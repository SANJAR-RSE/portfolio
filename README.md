# Sanjar — Portfolio

Personal portfolio site for Sanjar, a full-stack developer building web
applications with React, Next.js, Node.js and Express.

Live projects featured: [Pulse](https://github.com/SANJAR-RSE/Pulse),
[FinanceSave](https://github.com/SANJAR-RSE/financesave), and
[Avto Ijara](https://github.com/SANJAR-RSE/avto-ijara).

## Stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- [Tailwind CSS](https://tailwindcss.com)
- [Framer Motion](https://motion.dev) for subtle scroll/hover animations
- [Lucide](https://lucide.dev) icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

All personal info, contact details and navigation live in
`src/lib/config.ts`. Project and skill data live in `src/lib/data.ts`.
Update those two files to change site content — no component edits needed.

## Deploy

Deploy on [Vercel](https://vercel.com/new) — zero configuration needed for
a standard Next.js app.
